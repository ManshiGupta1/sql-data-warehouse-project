# SQL Server Data Warehouse & BI Analytics

This project demonstrates the development of an end-to-end SQL Server Data Warehouse that integrates data from CRM and ERP source systems. The data is extracted, cleaned, transformed, integrated, and modelled into a structured analytical warehouse.

The project follows a layered approach from source data → Bronze → Silver → Gold → BI analytics and reporting.

## 🏗️ Data Architecture

The project follows a layered Medallion Architecture consisting of Bronze, Silver, and Gold layers.

![Data Architecture](docs/data_architecture.png)

---

## 🎯 Objective

The main objective is to build a reliable analytical solution that enables businesses to understand:

- 👥 Customer Behavior
- 📦 Product Performance
- 💰 Sales Trends
- 📊 Overall Business Performance

---

## ⚙️ Project Specifications

### 📥 Data Sources

- **CRM:** Customer, sales, and transaction-related data
- **ERP:** Product, customer, and operational data

### 🧹 Data Quality

- Data cleansing and standardization
- Handling missing and invalid values
- Removing duplicates
- Data validation and consistency checks

### 🔗 Data Integration

- Combining CRM and ERP datasets
- Resolving differences in structure and formats
- Creating unified business entities
- Applying transformation rules

### 🧩 Data Modelling

- Dimensional modelling
- Fact and dimension tables
- Star Schema
- Surrogate keys
- Defined data grain and relationships
